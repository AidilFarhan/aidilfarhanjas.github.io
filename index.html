RekodJa : Automated Job Tracker

Chrome Extension & Web App
Personal Engineering Project : Dual-Client Google Integration
The Problem

Job hunting involves tracking dozens of applications across diverse platforms. Manual spreadsheet logging is slow, fragmented, and prone to abandonment.

The Solution

Two interconnected tools sharing one single Google Sheet source: save live job details instantly via browser extension, then analyze and manage follow-ups via the web dashboard.

REKODJA SYSTEM ARCHITECTURE • LIVE DATA PIPELINE Zero-server client privacy
  • Automated DOM Parsing: Dynamically extracts role title, hiring company, date, and link directly from active job boards, eliminating manual data entry.
  • Direct Cloud Persistence: Authenticates via OAuth 2.0 to write rows straight into the candidate's personal Google Sheet.
  • Privacy-First Architecture: Pure client-side data transmission with zero intermediate backend storage, ensuring zero hosting costs and full confidentiality.
  • Session & Dashboard Analytics: Secure Google OAuth session handling with visual breakdowns of application velocity, response rates, and interview pipeline stages.
  • Bidirectional Synchronization: Reads existing applications directly from connected Google Sheets and allows live status updates with automatic two-way sync.
  • Gmail Integration Engine: Scans user email threads to identify recruiter responses and application acknowledgments for one-click verification.
